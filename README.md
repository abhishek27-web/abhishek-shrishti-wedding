## GitHub Pages
1. Create a new GitHub repository.
2. Upload **everything in this folder**, keeping the `assets` folder intact.
3. Make sure the main file is named `index.html`.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch** → `main` → `/ (root)`.
6. Save and open the GitHub Pages URL GitHub provides.

The HTML uses relative paths such as `assets/couple-art.png`, so the images will load correctly when the complete folder is uploaded.
