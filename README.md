# Abhishek & Shrishti — Wedding Invitation

GitHub Pages-ready static wedding invitation.

## Publish
Upload the entire folder contents, keeping `index.html` and `assets/` together. Enable GitHub Pages from the repository's Pages settings and select the `main` branch/root.

The opening is a CSS 3D ribbon-and-bow sequence: tap the invitation, the knot releases, bow/tails move away, then the two paper doors open outward and the invitation reveals the couple journey.

Wedding location: **Sriram Garden, Rishikesh, Uttarakhand**.

Opening artwork: assets/opening-bow-reference.jpg is the supplied reference image and is embedded locally in the invitation.
